# Homebrew tap for Paperclip

```bash
brew install --cask annuai/tap/paperclip
```

Paperclip is a friendly desktop paperclip: jokes, quotes, water and stretch reminders, a focus timer, and answers to your questions. Source and releases: https://github.com/annuai/paperclip

The app isn't signed by Apple yet, so the first time you open it, right-click Paperclip in Applications and choose **Open**.
